Every recipe uses 1-based inclusive command-line regions. Track files retain the coordinate convention of their own format—for example, BED is zero-based and half-open.

Minimal snapshots

Indexed BAM

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --output_dir out --output_name locus

CRAM with its reference

locus-snap --bam sample.cram --fasta GRCh38.fa \
  --region chr1:100001-101000 --output_name cram-locus

Add context around a point variant

locus-snap --bam sample.bam --region chr7:140453136-140453136 \
  --flank 75 --center_guide --output_name point-variant

Publication output

Vector SVG

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --output_name figure.svg --fig_width 16

High-resolution PNG with right-aligned title

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --title_align right --fig_width 16 --dpi 300 \
  --output_name figure.png

Clean panel without legend or genomic grid

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --no_legend --grid_mode none --no_ideogram --output_name clean

Highlight an interval through all tracks

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --highlight chr1:100420-100510 \
  --highlight_color '#ffd54f' --highlight_alpha 0.22

Annotation and signal tracks

Automatic and custom transcript tracks

# Built-in human RefSeq selection
locus-snap --bam sample.bam --region chr17:7668000-7680000 --refseq hg38

# Explicit GTF
locus-snap --bam sample.bam --region chr17:7668000-7680000 \
  --custom_track 'genes.gtf.gz,gtf,Transcripts,#17217a,collapse,0.8'

Signal, peaks, variants, and CNV

locus-snap --bam sample.bam --region chr8:127000000-129000000 \
  --track accessibility.bw \
  --custom_track 'peaks.narrowPeak,narrowpeak,ATAC peaks,#188977,density,0.7' \
  --custom_track 'calls.vcf.gz,vcf,Variants,#d95d55,pack,0.8' \
  --custom_track 'segments.seg,seg,Copy number,#4c7edb,collapse,0.8'
Compressed interval tracks need indexes.

Use BGZF plus tabix for BED, GFF/GTF, VCF, peak, TAD, signal, and BEDPE inputs.

Samples and loci

Stack samples

locus-snap \
  --bam tumour.bam --sample_label Tumour \
  --bam normal.bam --sample_label Normal \
  --bam relapse.bam --sample_label Relapse \
  --region chr7:55086500-55087000 \
  --output_name cohort-locus

Associate a VCF with each sample

locus-snap \
  --bam tumour.bam --sample_label Tumour --vcf_companion tumour.vcf.gz \
  --bam normal.bam --sample_label Normal --vcf_companion none \
  --region chr7:55086500-55087000

Compare independent loci

locus-snap --bam sample.bam \
  --region chr3:38639720-38639860 --region_label Breakpoint-A \
  --region chr8:128747900-128748080 --region_label Breakpoint-B \
  --link_breakpoints --output_name linked-loci

Select and organize read evidence

Only anomalous reads

locus-snap --bam sample.bam --region chr3:38639000-38640500 \
  --only discordant split softclip --sort_by sa_count

Group reads by BAM tag

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --group_by_tag RG \
  --tag_color tumour='#d95d55' --tag_color normal='#4c7edb'

Haplotype lanes

locus-snap --bam phased.bam --region chr1:100001-101000 \
  --haplotype_view split --haplotype_filter 1 2

Large-depth locus

locus-snap --bam deep.bam --region chr1:100001-101000 \
  --display_mode squish --max_alignment_depth 150 --max_rows 80

Analysis exports

Per-read metrics

locus-snap --bam sample.bam --region chr1:100001-101000 \
  --metrics_tsv read-metrics.tsv --output_name metrics-view

RNA junction and fusion table

locus-snap --bam rna.bam --fasta reference.fa \
  --region chr2:42490000-42530000 --rna_mode \
  --rna_evidence_tsv rna-evidence.tsv

Batch HTML report

locus-snap --bam tumour.bam --bam normal.bam \
  --batch_regions candidates.bed --flank 100 \
  --report report.html --threads 4 --output_dir review

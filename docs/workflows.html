Small-variant review

Use a FASTA and a close window to reveal mismatches. Sorting by the candidate base moves alternative-supporting reads together; the coverage track can display ALT/depth, VAF, strand counts, base quality, and MAPQ.

locus-snap \
  --bam tumour.bam \
  --fasta reference.fa \
  --region chr7:55086720-55086950 \
  --sort_by base \
  --sort_base_position 55086812 \
  --show_variant_counts \
  --min_baseq 20 \
  --min_variant_mapq 20 \
  --center_guide \
  --output_name snv-review
Base labels require close zoom.

Reference and individual read bases appear only below --max_reference_span. The default threshold is 250 bp.

Phased pharmacogenomic star alleles

This GRCh37 example models CYP2D6*4.001/*1. wgsim generates two 15× haplotypes as 2×150 bp reads with realistic insert-size and error distributions; BWA-MEM then maps them against the complete hg19 genome. MAPQ 0 primary alignments are deliberately retained, allowing CYP2D6/CYP2D7 homology to create uneven coverage and pale low-confidence read pairs. Five non-reference markers from the legacy *4A/*4.001 definition are phased as 1|0 and linked to HP1 through the same PS value.

export LOCUSSNAP_HG19_FASTA=/path/to/ucsc.hg19.fasta
python3 generate_demo_data.py
locus-snap \
  --bam out/demo_data/alignments/demo_cyp2d6_star4.bam \
  --fasta out/demo_data/reference/demo_cyp2d6_reference.fa.gz \
  --region chr22:42522001-42527200 \
  --custom_track 'out/demo_data/annotations/demo_cyp2d6.gtf,gtf,CYP2D6 canonical transcript,#17217a,collapse,0.72' \
  --custom_track 'out/demo_data/variants/demo_cyp2d6_star4.vcf.gz,vcf,Phased VCF · HP1 *4.001 (no function) / HP2 *1,#7a1f5c,expand,1.18' \
  --haplotype_view split --haplotype_filter 1 2 \
  --view_as_pairs --show_exon_numbers --min_mapq 0 \
  --genome hg19 --refseq none \
  --output_name 42_cyp2d6_star4_haplotype

The allele naming follows PharmVar. The figure is an educational visualization, not a star-allele calling or clinical phenotype report.

Structural variants and translocations

Pair evidence within one locus

locus-snap \
  --bam sample.bam \
  --region chr3:38639200-38640200 \
  --view_as_pairs \
  --only discordant split softclip \
  --sort_by sa_count \
  --show_indel_lengths \
  --output_name breakpoint-evidence

Linked partner loci

locus-snap \
  --bam sample.bam \
  --region chr3:38639720-38639860 \
  --region chr8:128747900-128748080 \
  --region_label 'Left breakpoint' \
  --region_label 'Right breakpoint' \
  --link_breakpoints \
  --view_as_pairs \
  --output_name translocation

Use --mate_view when the partner is not known in advance. LocusSnap estimates a mate window from discordant pairs, split alignments, or soft clips.

RNA-seq junctions and fusions

The RNA preset reads splice junctions from CIGAR N operations, compares boundaries with visible BED12/GFF/GTF models, derives motifs from FASTA, and clusters fusion support from SA tags plus distant or inter-chromosomal mates.

locus-snap \
  --bam tumour-rna.bam \
  --fasta reference.fa \
  --region chr2:42490000-42530000 \
  --track transcripts.gtf.gz \
  --rna_mode \
  --min_junction_reads 3 \
  --min_junction_anchor 12 \
  --sashimi_strand split \
  --rna_strandness reverse \
  --junction_labels full \
  --min_fusion_reads 3 \
  --rna_evidence_tsv rna-evidence.tsv \
  --output_name rna-review
  • K denotes an annotated exon boundary; N denotes a novel junction.
  • Full labels add canonical motifs such as GT-AG.
  • Fusion support is labelled S#/P# for unique split reads and spanning pairs.

Corroborate a fusion across DNA and RNA

Repeat both BAM arguments and both breakpoint regions to make a sample-by-locus matrix. For EML4::ALK V1, the DNA rows should expose the large intrachromosomal inversion through same-strand pairs and split alignments, while the RNA rows should terminate at EML4 exon 13 and resume at ALK exon 20.

locus-snap \
  --bam tumour-dna.bam --bam tumour-rna.bam \
  --sample_label 'DNA-seq · inv(2)' \
  --sample_label 'RNA-seq · EML4(e13)::ALK(e20), V1' \
  --region chr2:29445751-29448650 \
  --region chr2:42521851-42523650 \
  --track transcripts.gtf.gz \
  --rna_mode --rna_sample 2 \
  --show_exon_numbers --view_as_pairs --link_breakpoints \
  --fusion_min_distance 1000000 \
  --output_name eml4-alk-dna-rna

Long reads and base modifications

locus-snap \
  --bam nanopore.bam \
  --fasta reference.fa \
  --region chr12:100000-112000 \
  --long_read_mode \
  --modification_code 5mC \
  --min_mod_probability 0.8 \
  --output_name long-read-mods

MM/ML calls are drawn on reads and summarized as a modification-fraction track. Use --base_modifications instead when modification display is wanted without the long-read colour preset.

UMI molecule consensus

locus-snap \
  --bam targeted.bam \
  --fasta reference.fa \
  --region chr17:7577000-7577200 \
  --molecule_mode \
  --molecule_tag auto \
  --min_family_size 2 \
  --molecule_consensus_fraction 0.7 \
  --show_variant_counts \
  --output_name molecule-evidence

Positional MI/RX/UB families collapse into consensus molecules. Coverage and VAF then represent independent molecules rather than PCR copies.

Multi-sample and batch reports

locus-snap \
  --bam tumour.bam --sample_label Tumour \
  --bam normal.bam --sample_label Normal \
  --bam relapse.bam --sample_label Relapse \
  --batch_regions candidates.vcf.gz \
  --flank 100 \
  --report review/report.html \
  --threads 4 \
  --output_dir review/plots

The report is self-contained and retains input order. Repeated --vcf_companion values can add one variant track per sample; use none as a placeholder.

Hi-C TADs and chromatin loops

LocusSnap accepts domain/TAD intervals, BEDPE loops, and contact-matrix tracks. These can be combined with genes, variants, and alignments around a locus.

locus-snap \
  --bam sample.bam \
  --region chr8:127000000-130000000 \
  --track domains.tad.bed \
  --track loops.bedpe.gz \
  --custom_track 'contacts.bedpe,bedpe,Hi-C contacts,#a50f15,triangle,1.2' \
  --no_alignments \
  --output_name chromatin-context

Contact maps use a reddish sequential palette by default. Track configuration controls triangular orientation and visual height; see Configuration.

Installation

Install from PyPI

python3 -m pip install locus-snap
locus-snap --help

LocusSnap supports Python 3.9 and newer. For a reproducible environment:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install locus-snap

Install the current source checkout

git clone https://github.com/GENCARDIO/LocusSnap.git
cd LocusSnap
python -m pip install -e ".[dev]"
pytest -q

The compatibility entry points python3 locus_snap.py and python3 -m locus_snap accept the same arguments as locus-snap.

Prepare the inputs

InputRequirementWhy it is used
BAMCoordinate-sorted and indexedAlignments, coverage, pair geometry, tags, CIGAR and SA evidence.
CRAMIndexed, plus matching FASTASame evidence as BAM; the reference is required for decoding.
FASTAMatching assembly; indexableReference bases, mismatches, splice motifs, and CRAM decoding.
Regionchrom:start-endCoordinates are 1-based and inclusive.
 
samtools sort -o sample.sorted.bam sample.bam
samtools index sample.sorted.bam
samtools faidx reference.fa
Contig names must agree.

If the BAM uses chr1, the FASTA and annotation tracks must normally use chr1 too. A 1/chr1 mismatch is a common reason for an empty track.

Create the first snapshot

locus-snap \
  --bam sample.sorted.bam \
  --fasta reference.fa \
  --region chr9:101867481-101867620 \
  --output_dir out \
  --output_name locus

The result is out/locus.png. Human hg19/GRCh37 and hg38/GRCh38 BAMs can receive automatic cytoband and RefSeq context. Disable network-backed RefSeq resolution with --refseq none.

Choose another output format

# Editable vector output
locus-snap --bam sample.bam --region chr1:1000-2000 \
  --output_name figure.svg

# Publication-resolution raster output
locus-snap --bam sample.bam --region chr1:1000-2000 \
  --output_name figure.png --fig_width 16 --dpi 300

Supported formats are PNG, SVG/SVGZ, PDF, JPEG, TIFF, and WebP.

Read the result

  • The chromosome overview marks the displayed interval in red.
  • The scale bar and genomic axis report the local span.
  • Coverage is calculated from all retained reads, even when alignment rows are downsampled.
  • At close zoom, mismatching and soft-clipped nucleotides use IGV-compatible base colours.
  • The Alignment legend explains concordant, discordant, insertion, deletion, and strand-specific evidence that is present.

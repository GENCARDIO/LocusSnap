Regenerate the gallery

From a source checkout, the generator first creates deterministic indexed inputs and then renders the maintained example set:

python3 generate_demo_data.py
bash regenerate_demo_examples.sh

Images are written to out/. The website keeps selected copies under docs/assets/images/ because GitHub Pages publishes only the docs directory.

regenerate_demo_examples.sh contains the command, input paths, dimensions, and resolution for every maintained figure.

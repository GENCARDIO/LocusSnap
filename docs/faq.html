Test BAM access with --bam and --region first. Then add FASTA, annotations, evidence modes, and styling one group at a time.

“The BAM has no index”

Coordinate-sort and index the file. For BAM:

samtools sort -o sample.sorted.bam sample.bam
samtools index sample.sorted.bam

The index should normally be named sample.sorted.bam.bai or sample.sorted.bai. CRAM uses a .crai index.

CRAM fails to open or decode

Supply the exact reference assembly used to create the CRAM:

samtools faidx reference.fa
locus-snap --bam sample.cram --fasta reference.fa \
  --region chr1:100001-101000

A FASTA from a different patch release can fail even when chromosome names look identical.

Reference bases or mismatches are missing

  • Provide --fasta and make sure its contig names match the alignment file.
  • Zoom below --max_reference_span, which defaults to 250 bp.
  • Set --max_reference_span 0 only when you deliberately want to hide the base track.
  • Remember that CLI regions are 1-based inclusive.

A genomic track is empty

Compressed track lacks an index

Ordinary gzip is not enough for regional access. Create a BGZF file and tabix index:

bgzip annotations.bed
tabix -p bed annotations.bed.gz

Use the appropriate tabix preset for GFF or VCF. BigWig is self-indexed.

Coordinates or contigs do not overlap

BED-like formats are normally zero-based and half-open; VCF positions are 1-based. Verify chr1 versus 1 and inspect a few records with tabix FILE REGION.

The automatic gene track is missing

Automatic RefSeq selection requires an exact BAM contig-length match for a supported human assembly. Choose --refseq hg38 or --refseq hg19, provide an explicit GTF/GFF, or use --refseq none.

The image is too tall or memory-heavy

Use compact rows and cap only the visual layer:

locus-snap --bam deep.bam --region chr1:100001-120000 \
  --display_mode squish \
  --max_alignment_depth 100 \
  --max_rows 80

Coverage, summaries, and TSV exports still use all retained reads. For a broad track-only overview, add --no_alignments.

Mate view cannot find a locus

The selected evidence source needs enough partner coordinates:

--mate_view --mate_window_source discordant
--mate_view --mate_window_source split
--mate_view --mate_window_source softclip

For known breakpoints, use repeated --region with --link_breakpoints instead of partner inference.

Why are low-MAPQ reads pale?

Alignment fills are shaded by MAPQ up to --mapq_cap. Use --no_mapq_shading when uniform fill is preferable.

Why are only some soft-clipped bases labelled?

Individual nucleotides appear only at close zoom. Wider windows retain the soft-clipped segment without base labels.

Can LocusSnap read raw .hic or .cool matrices?

Not directly. Export called TADs to BED-like intervals, called loops to BEDPE, or binned cis contacts to scored BEDPE. LocusSnap renders those processed features alongside the locus.

Report a reproducible problem

Open a GitHub issue with:

  • locus-snap --help version context and python --version;
  • the complete command with sensitive paths anonymized;
  • the traceback or terminal error;
  • input format, index presence, reference assembly, and contig naming convention;
  • a minimal synthetic or shareable locus when possible.
python -c "import locus_snap; print(locus_snap.__version__)"

Command-line interface

locus-snap --bam BAM (--region REGION | --batch_regions FILE) [OPTIONS]
--bam PATHIndexed BAM or CRAM; repeat for stacked sample panels.
--region LOCUS1-based inclusive chrom:start-end; repeat for explicit multi-locus columns.
--batch_regions FILEBED3/BED4 or VCF/BCF candidates rendered in one run.
--fasta PATHReference bases, mismatch detection, splice motifs, and CRAM decoding.
--config PATHValidated reusable YAML preferences and styles.

Regions, samples, and reports

--flank BPAdd context to each requested region.
--region_label LABELName the corresponding repeated region.
--link_breakpointsConnect centres of adjacent multi-locus panels.
--sample_label LABELName the corresponding repeated BAM.
--vcf_companion VCFAttach one VCF per BAM; use none as a placeholder.
--report [PATH]Build a self-contained HTML batch report.
--threads NUse isolated worker processes for batch regions.

Python API

Render a snapshot

from locus_snap.snapshot import BamSnapshot

snapshot = BamSnapshot(
    bam="sample.bam",
    chrom="chr1",
    start=100_000,       # zero-based internal coordinate
    end=101_000,         # half-open internal coordinate
    fasta="reference.fa",
    output_dir="out",
    output_name="api-locus",
    display_mode="squish",
)
summary = snapshot.snap(metrics_tsv="out/read-metrics.tsv")
print(snapshot.output_path, summary.n_reads)
Coordinate convention changes at the API boundary.

The CLI accepts 1-based inclusive regions. BamSnapshot and plugin TrackRegion use zero-based, half-open intervals.

RNA evidence helpers

from locus_snap import collect_splice_junctions, collect_fusion_evidence

junctions = collect_splice_junctions(reads, minimum_anchor=12)
fusions = collect_fusion_evidence(reads, "chr1", minimum_mapq=20)

Plugin interface

The public plugin surface exports TrackPlugin, TrackCanvas, TrackRegion, PluginTrackSource, discovery helpers, and API-version constants from locus_snap.

Version and compatibility

LocusSnap 0.4.0 supports Python 3.10–3.14. BAM/CRAM parsing is provided by pysam; plotting uses Matplotlib. The tox matrix and GitHub Actions exercise the supported Python versions.

Precedence

Explicit command-line arguments override YAML preferences. This makes a lab-wide style reusable while preserving one-off analytical choices:

locus-snap --config lab-style.yaml \
  --bam tumour.bam --region chr7:55086500-55087000 \
  --grid_mode bands --title_align center
Keep data paths out of the visual theme when possible.

A portable theme usually contains colours, dimensions, and display defaults. Add sample-specific tracks on the command line or in a separate workflow configuration.

Layout and figure composition

--layout packGreedy IGV-style row packing; best general default.
--layout expandOne read per row, useful when sorting evidence.
--display_mode squishCompact alignment rows for deep or multi-sample views.
--grid_mode major_minorMajor genomic coordinates plus subdivisions.
--grid_mode bandsAlternating genomic background bands.
--title_align left|center|rightPlaces the figure-level title and subtitle.
--no_legendRemoves the legend and reclaims its figure space.

Use --highlight repeatedly to shade user-defined intervals through every applicable track.

Colour conventions

The default base palette follows IGV: adenine green, cytosine blue, guanine orange, and thymine red. Alignment colour categories share one legend bucket and appear only when present. Small-insert evidence uses a darker variant of the RR palette.

Matplotlib colour names, hex strings, and other Matplotlib-compatible colour forms are accepted. Quote hex values in YAML and shell commands.

The custom-track high colour controls the strong-contact endpoint. Use BEDPE arcs for called loops and triangle for binned cis contacts.

Custom track plugins

External packages can implement the stable API-v1 interface without importing Matplotlib axes:

from locus_snap import TrackPlugin

class ScoreTrack(TrackPlugin):
    name = "score-track"
    default_label = "Model score"

    def fetch(self, region, options):
        return query_scores(region.chrom, region.start, region.end)

    def render(self, canvas, payload, region, options):
        canvas.set_y_limits(0, 1)
        canvas.fill_between(payload.positions, payload.values, alpha=0.25)
        canvas.line(payload.positions, payload.values)
# Packaged entry point
--plugin_track model-score sample=tumour smoothing=25

# Direct import during development
--plugin_track my_package.tracks:ScoreTrack sample=tumour

See the bundled GC-content plugin for a complete runnable example.
